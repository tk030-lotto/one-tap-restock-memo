# 消耗品補充ワンタップメモ（one-tap-restock-memo）

家庭で消耗品がなくなった瞬間に1タップで記録し、次回の買い物対象を迷わず把握できるワンタップメモツールです。

## こんなときに

- トイレットペーパーや洗剤が切れた瞬間、メモ帳を開いて文字を打つのが面倒なとき
- 買い物中に「何を買うべきだったか」をひと目で確認し、カゴに入れたらすぐに消し込みたいとき
- 多機能なToDoアプリのフォルダ分けや期日設定が煩わしく、シンプルにリストだけ管理したいとき

## 主な機能

- **よく使う項目から1タップ追加**: 頻出する消耗品をチップから1タップで要補充リストに追加できます。
- **1タップで補充完了**: 買ったらリストのボタンを押すだけで「補充済み」へ移動します。
- **間違えても安心な「元に戻す」**: 直前の操作を3.5秒間、画面下部の通知から1タップで取り消せます。
- **履歴の自動学習**: 新しく手動入力した項目も次回から「よく使う項目」に自動表示されます。
- **オフライン動作対応（PWA）**: ホーム画面に追加でき、電波の届きにくい店舗でも動作します。

## 使い方

### ブラウザで使う（かんたん）

1. [ツールを開く](https://zero-dev.jp/one-tap-restock-memo/) をクリックします。
2. なくなった物があれば、「よく使う項目から1タップ追加」の中にあるボタン（例: 「＋ トイレットペーパー」）を押します。
3. 画面上の「要補充リスト」に追加されます。
4. リストにない物は、画面下の「なくなった物を入力」の欄に名前を入力し、「追加」を押します。
5. 買い物が終わったら、リストの「補充する」を押すと、「補充済み」へ移動します。
6. 間違えて押したときは、画面下に表示される「元に戻す」を押すと元に戻せます。

### ホーム画面に追加して使う（スマホ推奨）

#### iPhone（Safari）
1. Safariでツールを開きます。
2. 画面下の共有ボタン（四角から矢印が出ているアイコン）を押します。
3. 「ホーム画面に追加」を選び、右上の「追加」を押します。

#### Android（Chrome）
1. Chromeでツールを開きます。
2. 画面右上のメニュー（︙）を押します。
3. 「アプリをインストール」または「ホーム画面に追加」を選びます。

## うまくいかないとき

- **保存したはずのデータが消えたとき**: ブラウザの「履歴を削除」「サイトデータを消去」を行うと、保存されたデータも消去されます。
- **新しい項目が追加できないとき**: 入力欄が空になっていないか確認してください（空白のみの場合は追加されません）。また最大50文字まで入力できます。

## 動作環境

- モダンWebブラウザ（Google Chrome、Safari、Microsoft Edge、Firefox の最新版）
- スマートフォン（iOS Safari / Android Chrome）および PC

## 制限・注意

- 入力したデータはお使いの端末のブラウザ内（`localStorage`）にのみ保存されます。
- 異なる端末間（スマートフォンとパソコンなど）での自動同期には対応していません。
- プライベートブラウズモード（シークレットモード）では、タブを閉じるとデータが消える場合があります。

## 外部通信

外部への通信は行いません（端末内でのみ動作）。

## 開発者向け

### ファイル構成

```text
消耗品補充ワンタップメモ/
├── index.html       # メインHTML
├── style.css        # スタイル定義
├── sw.js            # Service Worker（PWAオフライン対応）
├── manifest.json    # Web App Manifest
├── js/
│   ├── app.js       # エントリーポイント・イベントバインド
│   ├── state.js     # 状態管理・ロジック
│   ├── storage.js   # localStorage入出力・初期データ
│   └── ui.js        # DOM生成・描画
└── icons/           # PWA用アイコン画像
```

### ローカルでの起動

ES Modules および Service Worker を利用しているため、ローカルHTTPサーバー経由で起動してください。

```bash
python -m http.server 8080 --bind 127.0.0.1
```
ブラウザで `http://localhost:8080` を開きます。

`--bind 127.0.0.1` は、同じネットワーク上の他の端末から見えないようにするための指定です（同梱の `ツール起動.bat` も同じ待ち受けになります）。
